# Documentation screenshots

The browser screenshots were captured on 20 November 2026 from the installed
[Scope v0.8.0 production release](https://github.com/antonisPanos/scope/releases/tag/v0.8.0)
on macOS 27.2.1. The light and dark variants are native window captures.

## Content and privacy

Aegean Studio is a fictional exhibition project created for the screenshots. Its
fixtures include six original procedural coastal illustrations, project notes
and a 102-entry seasonal catalog. Finder color tags were added to the demo files
before opening them in Scope. Scope only read the fixtures. The sidebar was
hidden and the search location column shows only the disposable project path.

## Update notice capture (24 November 2026)

`update-notice.png` shows the native titlebar notice from an isolated Scope Dev
build on macOS 27.2.1. The build reported version 0.7.0 to the checker, which
found the published 0.8.0 release. The capture is cropped to the notice and shows
only its version text and buttons.

## Folder view settings capture (19 November 2026)

`folder-view-settings.png` is an unedited native Scope Dev Settings window
capture on macOS 27.2.1 with Xcode 27.2. It shows only preferences, with no
personal paths or files. A temporary development hook opened and captured the
Settings window; the hook was removed before the final build. The smaller-window
layout is also rendered by the app tests.

## Folder Info captures (19 November 2026)

The three `folder-info-*.png` images show this change's native Scope Dev Info
windows on macOS 27.2.1 with Xcode 27.2. Their only content comes from owned,
disposable fixtures under `/private/tmp/ScopeFolderInfoQA-6uf2pyqw`: 20,000
one-byte files, a readable file beside an unreadable subfolder, and an unreadable
root. The app only read these fixtures. Every image was inspected for private
content; no personal files, user names or home paths are visible.

A temporary development hook selected each Info window and resized it to 390
points tall for capture. That hook and temporary worker-timing instrumentation
were removed before the final build. The images are unedited window captures.

## Capture workflow

1. Open the installed production release and browse disposable fixtures that
   contain only demo material.
2. Hide the sidebar and path bar where appropriate, wait for thumbnails and
   previews to finish loading, and capture the Scope window.
3. Inspect each image for personal information, incomplete previews, clipping
   and accurate captions. Check the light and dark variants before publishing.
